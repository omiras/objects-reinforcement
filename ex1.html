Ejercicio 1 · Consultar datos de una reserva

Antes de empezar

Encadena propiedades para leer datos anidados y usa includes para comprobar si un array contiene un servicio. 

const vuelo = { salida: { aeropuerto: "JFK" } };
console.log(vuelo.salida.aeropuerto); // JFK

Tu turno

Abre la consola del navegador (F12 → Consola).

Completa los console.log de los apartados 1 a 7. Cada línea debe mostrar el dato solicitado.

Edita el último <script>, guarda el archivo y recarga la página.
